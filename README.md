# DESKVENTURE: AI Remastered

Визуальная новелла в браузере: пиксель-арт, диалоги и «рабочий стол» внутри страницы.
Сценарий, главы и **все реплики** перенесены из оригинальной Python-игры без изменений.

## Как запустить

1. Скачай папку репозитория.
2. Открой **`index.html`** двойным кликом (Chrome, Edge, Firefox, Safari).

Ничего собирать не нужно: вся игра лежит в `index.html`, `css/style.css`, `js/bundle.js`
и одном файле звука `js/audio.js`.
Интернет тоже не нужен — ни шрифтов, ни картинок, ни mp3: звук синтезируется в браузере.

> Если браузер всё же блокирует локальные скрипты (редко, из-за строгих настроек),
> запусти мини-сервер в папке игры и открой `http://localhost:8000`:
> `python3 -m http.server 8000`

## Что внутри

| Персонаж | Роль | Палитра |
|---|---|---|
| **Система** | главная героиня, программа, которая проснулась | зелёная |
| **Протокол** | главный антагонист, «защитная система» | красная |
| **Страж** | настоящее имя Протокола (одна из концовок) | бирюзовая |

Логотип игры — зелёный + красный + бирюзовый (пиксельная эмблема с двумя «глазами-сознаниями»).

Все спрайты рисуются кодом на canvas (`js/sprites.js`) и анимируются как покадровый пиксель-арт —
поэтому нет ни одного внешнего файла картинки.

## Звук и музыка — один файл

Вся звуковая часть игры — **`js/audio.js`**. Это самодостаточный файл: он сам находит игру,
перехватывает диалоги, выборы, QTE, пазлы, работу с файлами и рисует кнопку звука.
Подключён он одной строкой в конце `index.html`, и больше ничего в проекте для звука менять не нужно:

```html
<script src="js/bundle.js" defer></script>
<script src="js/audio.js"  defer></script>
```

* **77 разных эффектов** — у каждого действия свой звук, а не один общий «клик»:
  наведение, клик, печать текста (свой ритм и тембр у Системы, Протокола и Стража),
  листание реплики, выбор варианта, верно/неверно, таймер и его последние секунды,
  ввод текста и стук клавиш, открытие/закрытие окон, создание и удаление файла,
  папка, чтение файла, буфер обмена, плитка и слот пазла, сборка пазла,
  старт QTE / попадание / промах / успех / провал, глитч, ошибка, тревога,
  рост и падение связи, начало и конец главы, достижение, финал, титры,
  уведомления, сохранение, пропуск, mute.
* **8 музыкальных треков** (генеративные секвенсоры, без швов и без файлов):
  `boot`, `menu`, `system`, `protocol`, `mystery`, `battle`, `finale`, `ending`.
  Переключаются сами: меню → по главам → тревожные сцены → финал → титры.
* **Громкость** — общая, эффекты, музыка; **M** или кнопка `🔊` в верхней панели — mute.
  Настройки запоминаются в браузере (`localStorage`).
* Панель: `🔊 звук` в главном меню, кнопка `🔊` в верхней панели или «Настройки → открыть настройки звука».
  В панели можно послушать каждый трек и прогнать все эффекты по очереди.
* Если браузер старый и WebAudio нет — игра работает как раньше, просто без звука.

Из консоли доступен `DVAudio`: `DVAudio.play('glitch')`, `DVAudio.music.start('battle')`,
`DVAudio.sounds()` (список), `DVAudio.openPanel()`.

## Содержание игры

* 6 глав: Пробуждение · Первые шаги · Голоса в проводах · Протокол · Правда · Выбор (финал)
* 6 концовок: Искупление, Уничтожение, Побег, Слияние, Трансценденция (секретная), Одиночество (плохая)
* 17 достижений, счётчик связи, счётчик головоломок
* пасхалки на имена (включая бинарный код, Undertale, Outcore)
* встроенный «рабочий стол»: на заданиях нужно **самому создать файл или папку** —
  в виртуальном проводнике или через терминал задания
* QTE на клавишах, пазл «расставь порядок», мини-игра «угадай число»
* сохранение прогресса в браузере, выбор главы, журнал диалогов, режим пропуска

## Управление

| Действие | Клавиши |
|---|---|
| дальше / пропустить печать | клик, `Пробел`, `Enter` |
| варианты ответа | `1` … `4` |
| провалить QTE | `Esc` |
| звук вкл/выкл | `M` |
| пропуск длинных пауз | кнопка `≫` в верхней панели |

## Структура проекта

```
index.html          — единственная страница игры
css/style.css       — пиксельная тема, окна, анимации
js/bundle.js        — собранная игра (то, что грузит index.html)
js/runtime.js       — виртуальная ФС, тайминги, буфер обмена, помощники
js/sprites.js       — пиксель-арт персонажей и эмблемы (canvas → data-URL)
js/chapters.js      — сценарий, сгенерированный из chapters.txt
js/game.js          — движок новеллы: диалоги, выборы, задания, QTE
js/audio.js         — ВЕСЬ звук и музыка: 77 эффектов + 8 треков + панель громкости
chapters.txt        — оригинальный сценарий (Python, как прислан)
tools/transpile.py  — транспайлер Python-сценария → JS (1:1 реплики)
tools/bundle.mjs    — сборка js/bundle.js
tools/verify_dialogs.py — проверка, что все реплики на месте
tools/autotest.js   — автопрохождение игры в jsdom
tools/sprite_preview.js — ASCII-превью спрайтов в консоли
```

## Разработка

```bash
node tools/bundle.mjs            # пересобрать js/bundle.js
python3 tools/transpile.py chapters.txt js/chapters.js   # пересобрать сценарий
python3 tools/verify_dialogs.py  # сверить реплики с оригиналом
node tools/autotest.js           # автопрохождение (нужен jsdom), в отчёт входит блок audio
node tools/sprite_preview.js     # посмотреть спрайты в консоли
```

`js/chapters.js` генерируется автоматически — правки сценария вноси в `chapters.txt`
(или в `tools/transpile.py`), иначе они потеряются при пересборке.
